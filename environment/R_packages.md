# R environment

The scripts use R packages including `Seurat`, `SeuratObject`, `Matrix`, `data.table`, `SingleCellExperiment`, `scDblFinder`, `edgeR`, `DESeq2`, `GSVA`, `WGCNA`, `CellChat`, `scTenifoldKnk`, and `scTenifoldNet`.

Exact session records from the study are retained under the relevant analysis-stage directories. Before a public release, create a single `renv.lock` (preferred) from a clean, successful rerun environment and replace this list with the lockfile.
