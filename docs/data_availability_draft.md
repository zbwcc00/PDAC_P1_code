# Draft Data Availability statement

All datasets analyzed in this study are publicly available from GEO and the resource portals listed in `metadata/public_data_manifest.tsv`, under the accessions and terms specified there. The versioned analysis code and processed, non-identifying source-data tables supporting the main and supplementary figures and reported statistics are archived in Zenodo (version `v0.1.2`, https://doi.org/10.5281/zenodo.22647158; concept DOI, https://doi.org/10.5281/zenodo.22647157) and are mirrored in the matching GitHub release at https://github.com/zbwcc00/PDAC_P1_code/releases/tag/v0.1.2. Raw third-party datasets are not redistributed in this archive. No newly generated human-participant data were produced.
