# Draft Data Availability statement

All datasets analyzed in this study are publicly available from GEO and the resource portals listed in `metadata/public_data_manifest.tsv`, under the accessions and terms specified there. The versioned analysis code and processed, non-identifying source-data tables supporting the main and supplementary figures and reported statistics are available in the GitHub release `v0.1.0` at https://github.com/zbwcc00/PDAC_P1_code/releases/tag/v0.1.0. This release will be archived in Zenodo before publication; the final Zenodo DOI will be inserted here after archival release. No newly generated human-participant data were produced.
